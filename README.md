# 🎮 GameStore

GameStore — oyunsevərlər üçün hazırlanmış onlayn oyun mağazasıdır. Oyunları axtara, filtrləyə, ətraflı məlumat əldə edə və səbətinizə əlavə edə bilərsiniz.

## 🛠️ Texnologiyalar

- React
- TypeScript
- Tailwind CSS
- React Router
- Vite

## 🚀 Qurulum

```bash
npm install
npm run dev
```

## 📄 Səhifələr

- **Ana Səhifə** — ən yüksək reytingli oyunlar
- **Oyunlar** — bütün oyunlar, axtarış və filter
- **Oyun Detayı** — ətraflı məlumat və rəy forması
- **Səbət** — əlavə edilmiş oyunlar və ödəniş
- **Haqqımızda** — layihə haqqında məlumat

## ⚙️ Əsas Funksiyalar

- Oyun axtarışı və janr filtri
- Qiymət və reytinqə görə sıralama
- Səbətə əlavə et, sil, miqdar artır/azalt
- Rəy forması (validation ilə)
- Loading state simulyasiyası
- Responsive dizayn
